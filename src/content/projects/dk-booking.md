## Overview

DK Booking is an event portal for Datorklubben at Tullinge Gymnasium. It gives attendees a place to read event information and make bookings, with a separate set of tools for organizers to manage the event and its bookings.

## Project focus

The work brings the public booking experience and organizer workflows into one site, connecting attendees with events while giving organizers a place to manage bookings.
